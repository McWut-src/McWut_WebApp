# Area: Games (`/games`)

Load this before touching anything under `Pages/Games/`, `Controllers/GamesController.cs`, `wwwroot/js/games*.js`, or `GameScoreService.cs`. Rules unique to this area; shared rules are in `docs/AGENT.md`.

## What it is
A single-player browser arcade hub where signed-in members play standalone JS games — currently featuring **Stack 3D** (`stack-3d`, Three.js isometric slab stacker), **Mini Crossword** (`mini-crossword`, responsive 5×5 crossword pack with on-screen QWERTY keyboard, pencil mode, hints, check, and clean-word combo scoring), **Minesweeper** (`minesweeper`, Canvas 2D neon minefield with tap/long-press touch controls, cascade combos, and first-click safety), **Neon Slope** (`neon-slope`, Three.js 3D downhill runner with procedural curved track, obstacles, collectable gems, jump physics, and 2D canvas fallback), **2048 Neon** (`merge-2048`, reactive 4×4 number merging grid with smooth animations, synthesized chord audio, undo support, and mobile touch D-pad/swipe), **Wacky Wheels** (`wacky-wheels`, family-friendly Canvas 2D ragdoll physics stunt buggy obstacle course), **Cyber Breakout** (`brick-breaker`, neon synthwave brick-breaker with multiballs, lasers, and explosive power-ups), **Hextris Neon** (`hextris`, fast-paced hexagonal match-3 puzzle with spring rotation, cascading combos, and explosive particle clears), **Meme Merge** (`meme-merge`, Suika-style 2D physics puzzle with color gradient tiers from Skull up to The Rock Side Eye and synthesized Vine Boom audio), and **Godzilla Rampage** (`godzilla-rampage`, Three.js 3D voxel pixel-art city destruction game — with automatic 2.5D Canvas fallback — starring a kid-crafted mossy orb-kaiju rescuing Baby Bronny James atop the Bronny Mega Tower) — and compete on a global high-score leaderboard.

## Golden Rules for All Games
1. **HTML / JS Standalone:** Pure single-player client-side execution. Zero server-side game simulation; the browser runs the complete game loop locally.
2. **Global Leaderboard Required:** Every game must integrate with the shared leaderboard (`GET /api/games/{key}/leaderboard` and `POST /api/games/{key}/scores`), tracking personal best scores, combo streaks, and total games played, while displaying member profile flair (display name, accent color pill, emblem badge, and status tag).
3. **Lightweight JS Engines & Vendors:** Games can use Three.js (`wwwroot/lib/three/three.min.js`), Alpine.js, HTML5 2D Canvas, or other lightweight JS vendors. All libraries must be vendored locally in `wwwroot/lib/` (no runtime external CDN calls). 3D/WebGL games must provide an automatic fallback (e.g., 2D isometric projection) for headless/restricted browsers.
4. **Mobile & Tablet Playable:** Every game must be responsive and fully playable via touch on phones and tablets (tap, swipe, touch-drag) as well as keyboard/mouse (Spacebar, Arrows, Click) on desktop. Viewports must resize dynamically across breakpoints (e.g., 390×844 to 1280×900).

## Behavior rules
- **Landing Page & Hub Architecture**: Direct visits to `/games` display the dedicated **Game Hub Landing Page** (`#game-hub-view`) with mobile-first, icon-first 2-column tiles (`.game-tile`) displaying large custom SVG icons, game titles, corner badges (`NEW`, `SOON`), and personal best pills (`[data-best-for]`, populated via `GET /api/games/me/bests`), with zero text bloat. Below the grid, the **Arcade Hall of Fame** card (`#hub-hall-card`) presents a horizontal snap-scrolling strip of game-selection chips (`.game-hall-chip` with `[data-hall-game]`) and high-score previews.
- **Stage Navigation & URL Routing**:
  - Direct visit `/games` -> `#game-hub-view` is visible; `#game-stage-view` is hidden; running game loops idle without physics/rendering load.
  - Clicking any catalog tile or "Play" button switches to `#game-stage-view`, activates the selected game, updates the URL to `/games?game={gameKey}` via `history.pushState`, and reveals the `All Games` back buttons (`#btn-back-to-hub` in header, `#btn-stage-back` in stage nav bar). On mobile screens (< 576px), back buttons collapse to icon-only and the stage switcher (`.game-hub-strip`) condenses to a horizontal icon-scroll bar saving ~250px of vertical height.
  - Tapping unreleased or "SOON" games surfaces a non-blocking `mcwut.toast` alert without navigating into an empty stage.
  - Clicking `All Games` returns to `#game-hub-view`, resets the URL to `/games`, and pauses running timers/loops.
  - Deep-linking (`/games?game=stack-3d`, `/games?game=neon-slope`, etc.) opens directly into the requested game stage without intermediate hub flashing.
  - Browser back/forward navigation (`popstate`) seamlessly switches between the Hub landing page and individual game stages.
- Each member has one leaderboard record per `GameKey` (`GameScores` table, unique index on `(GameKey, UserId)`), tracking `BestScore`, `BestCombo`, `GamesPlayed`, `AchievedAt`, and `LastPlayedAt`.
- Submitting a score increments `GamesPlayed`, updates `BestCombo` if higher, and replaces `BestScore` + `AchievedAt` only when the new score beats the player's previous record.
- Leaderboard rows sort in memory (`BestScore` descending, then `BestCombo` descending, then earlier `AchievedAt` ascending) because SQLite cannot `ORDER BY` a `DateTimeOffset`.
- Player rows render the member's `DisplayName` (resolved via `MemberLabel.Shown`), profile `AccentColor` pill (`#0b1f3a` fallback), optional `HeaderBadge` emblem, and `StatusTag`.
- Three.js is vendored locally at `wwwroot/lib/three/three.min.js`. `wwwroot/js/games-stack3d.js`, `wwwroot/js/games-neon-slope.js`, and `wwwroot/js/games-godzilla.js` use `THREE.WebGLRenderer` with automatic 2D isometric/perspective canvas projection fallbacks if WebGL context creation is unavailable on a headless or restricted device.
- Minesweeper is pure Canvas 2D (no vendored library). Difficulties are Easy 9×9/10, Medium 14×18/40, and Hard 16×24/76. The first reveal is always safe (it excludes the clicked 3×3 plus any pre-placed flags). Tap reveals, long-press or right-click flags, and the Flag mode button makes tap flag on touch. Scoring is per-cell base + cascade bonus + win/time bonus, capped at `1,000,000` (`GameScoreRules.MaxScore`); `BestCombo` is the largest cascade. Keep the shared leaderboard, difficulty chips, result overlay, and `?game=minesweeper` deep link wired when changing it.
- Neon Slope (`neon-slope`) is a high-speed 3D endless runner. It uses Three.js (`wwwroot/lib/three/three.min.js`) when WebGL is available and falls back smoothly to a 2D perspective wireframe canvas runner. Procedural track segments curve downhill with neon grid rails, red barrier obstacles, and floating cyan/amber gems (+100 score each, combo multiplier +1). Controls: Left/Right arrows or A/D or on-screen touch buttons steer; Space, Up arrow, or touch Jump jumps over gaps and low barriers. Speed scales continuously from 1.0× to 3.0×. Scoring: distance traveled + crystal bonuses, capped at `1,000,000` (`GameScoreRules.MaxScore`); `BestCombo` records the highest consecutive gem streak. Deep link: `?game=neon-slope`. Camera & coordinate rule: The Three.js camera looks down +Z from behind the ball (`z = ball.z - 6.8` looking towards `z = ball.z + 16.0`), so in Three.js right-handed coordinates world +X projects to screen-left and world -X projects to screen-right. Steering Left sets positive target velocity (`targetVx = 14.5`) and steering Right sets negative target velocity (`targetVx = -14.5`). The 2D canvas fallback projects screen X as `sx = width / 2 - (x - camX) * scale` to preserve exact coordinate parity between 3D and 2D fallback modes.
- 2048 Neon (`merge-2048`) is a reactive 4×4 sliding tile puzzle. Pure client-side JavaScript and CSS transitions (zero external library required). Controls: Swipe, keyboard arrows, W/A/S/D, or on-screen touch D-pad to slide tiles in 4 directions. When two identical tiles collide, they merge into the next power of 2 with a pop animation, neon glow tier (`.tile-2` through `.tile-2048` and `.tile-super`), and synthesized Web Audio pentatonic chime. Features single-step Undo (`n2048-undo-btn`), dynamic moves counter, and game-over/win overlays with "Keep Going" mode. Scoring: sum of merged tile values, capped at `1,000,000` (`GameScoreRules.MaxScore`); `BestCombo` records the highest tile achieved (e.g. 2048). Deep link: `?game=merge-2048`.
- Wacky Wheels (`wacky-wheels`) is a family-friendly 2D ragdoll physics stunt obstacle course rendered in pure Canvas 2D with a self-contained rigid-body + Verlet constraint solver (zero external library). Features a 2-wheel spring/damper suspension buggy, a 5-segment articulated Lego-style toy rider with breakable snap-joints (confetti/star bursts on wipeouts, zero gore), rolling hills, turbo launch ramp, 360° loop-the-loop, springboards, swinging wrecking balls, bouncy toy spike strips (soft hazard: bounce, combo reset, pin pop — never an instant wipeout), breakable crates, 15 bonus stars (+100 pts each), a front-mounted **toy baby doll co-pilot** worth **+500 SAFE DELIVERY** when still attached at the finish (lost on eject/crash), surface-aware wheel trails, brake skid marks, landing dust/shake/hitstop, checkered finish gate, and synthesized Web Audio engine/squeal/spring/star/horn/spike/baby sound effects. Includes an interactive **Level Editor** (`🛠 Level Editor` tab: draw roads/hills/boost ramps, stamp 360° loops, springboards, swinging wrecking balls, stacked crates, stars, toy spike strips, and finish gate, with live Test Play, Undo, and Publish) and **Member Levels** community browser (`🌐 Member Levels` tab, backed by `GameCustomLevels` table via `AddGameCustomLevels` migration, `GameLevelRules`, and `GameCustomLevelService`), showing creator member color pills, play/clear counts, course record scores/times, shareable deep links (`?game=wacky-wheels&level={id}`), and Remix support. Controls: `W`/`Up` or touch `▲` Gas, `S`/`Down` or touch `▼` Brake/Reverse, `A`/`D` or `Left`/`Right` or touch `↺`/`↻` Lean/Tilt, `Space` or touch `🚀` Eject Ragdoll / Super Boost, `R` or `⟲` Quick Restart. Scoring: 2,000 base completion + up to 3,000 time bonus + 100 per star + flip/stunt combo multipliers + 500 baby delivery, capped at `1,000,000` (`GameScoreRules.MaxScore`); `BestCombo` records the longest airtime/flip streak. Custom level JSON carries `strips`, `loops`, `springs`, `wreckingBalls`, `crates`, `stars`, and `spikes` (max 40, each `{x, y, w}` clamped 40–120 px). Deep link: `?game=wacky-wheels` (or `?game=wacky-wheels&level={id}`).
- Cyber Breakout (`brick-breaker`) is an ultra-juicy neon synthwave brick-breaker rendered in pure Canvas 2D with zero external runtime dependencies. Features responsive HiDPI canvas auto-scaling, paddle deflection physics (±60° angle agency based on contact point), elastic squash-and-stretch on ball and paddle, 15–25 piece physics fragment particle bursts, TNT explosive cascading bricks, power-up drops (Multi-Ball up to 9 balls, Twin Laser Blaster, Wide Paddle, Fireball piercing, and Slow-Mo), decaying trauma screen shake, hit-stop micro pauses, floating damage/combo popups, and synthesized Web Audio effects (paddle thud, pentatonic combo chirps, laser zaps, explosion noise bursts, and retro victory chords). Controls: Mouse, Touch drag, or `A`/`D`/Arrows steer; `Spacebar` or touch tap launches and fires lasers; `R` restarts. Deep link: `?game=brick-breaker`.
- Hextris Neon (`hextris`) is a fast-paced hexagonal match-3 puzzle game rendered in pure Canvas 2D with zero external runtime dependencies. Catch falling colored bars on the rotating central hexagon across 6 faces. When 3 or more matching colors connect horizontally across adjacent faces or vertically on the same face, they dissolve in explosive particle bursts, triggering inward gravity and cascading combo multipliers. Features critically-damped spring rotation, squash-and-stretch docking impact, hit-stop micro-pauses, radial shockwaves, danger perimeter pulsing, floating score popups, synthesized Web Audio effects (rotation tick, docking thud, ascending pentatonic combo chords, game over sweep), split-screen touch controls with on-screen visual hints, and desktop keyboard controls (`A`/`D` or Arrows rotate, `S`/`Down` soft drop, `Space` pause, `R` restart). Scoring: block points with dynamic combo multiplier (up to 10×), capped at `1,000,000` (`GameScoreRules.MaxScore`); `BestCombo` records the highest cascade streak. Deep link: `?game=hextris`.
- Meme Merge (`meme-merge`) is a Suika-style 2D physics puzzle game rendered in pure Canvas 2D with zero external runtime dependencies. Drop and merge classic meme stickers across a 10-tier neon color gradient ladder: Tier 1 Skull (violet, 2 pts) &rarr; Tier 2 Clown (blue, 4 pts) &rarr; Tier 3 Cap (cyan, 8 pts) &rarr; Tier 4 Bruh (emerald, 16 pts) &rarr; Tier 5 "6 7" (lime, 32 pts) &rarr; Tier 6 This Is Fine (amber, 64 pts) &rarr; Tier 7 Fire (orange, 128 pts) &rarr; Tier 8 Gigachad (crimson, 256 pts) &rarr; Tier 9 Big W (magenta, 512 pts) &rarr; Tier 10 **The Rock Bombastic Side-Eye** (radiant gold, 1,024 pts). Merging into The Rock triggers a synthesized Web Audio **Vine Boom** with sub-bass drop, screen shake trauma, and gold shockwaves; merging two Rocks triggers a Cosmic Ultra Vine Boom (+2,048 pts clear). Features 8-substep circle physics with mass-proportional impulse, rolling friction, elastic squash-and-stretch, overflow danger line with 3-second countdown, touch drag aiming and on-screen touch buttons (`◄`, `▼ DROP`, `►`), keyboard controls (`A`/`D` or Arrows aim, `Space`/`S`/`Down` drop, `R` restart), and global high-score leaderboard integration (capped at `1,000,000` via `GameScoreRules.MaxScore`). Deep link: `?game=meme-merge`. Physics/render invariants: scale the simulation uniformly and letterbox (`cssScale`, `cssOffsetX/Y`, `viewScale`, `viewOffsetX/Y` on the canvas transform) so resizing never stretches discs into ovals; point input through the same canvas rect; resolve only closing contacts (`approach = (v1 - v2)·n > 0`) with the standard mass-weighted impulse (`p = approach / totalMass`) and restitution 0 below 40 px/s (0.2 above) so resting piles settle instead of micro-bouncing; add only linear tangential contact friction and never exchange tangent velocity with `omega` (the old exchange had no matching linear impulse and pumped dense piles into endless spin); damp angular velocity hard, sleep slow bodies on linear speed alone (`restTimer` zeroes vx/vy/omega after 0.4s under 40 px/s), and zero `omega` when a body's net position moves under 6px in 0.25s; the overflow line (`DANGER_Y = 150`) sits inside the jar below the rim (`JAR_TOP_Y = 96`) and is driven by pile height (`highestTop`) with hysteresis (rise below 150, hold 150–174, drain only above 174) for the 3s countdown; `jarFill` maps `(FLOOR_Y - highestTop) / (FLOOR_Y - DANGER_Y)` from bodies older than 0.5s, and the "JAR FILL" meter is drawn last after every body so it can never be hidden; keep the drop cooldown at 0.8s and snap `dropperX` to `targetDropperX` on drop so memes land where the player aimed. The mobile touch bar (`#mm-touch-left`, `#mm-touch-drop`, `#mm-touch-right`) lives below `.mm-viewport`, never overlaid on the play area.
- Godzilla Rampage (`godzilla-rampage`) is a Three.js r128 voxel pixel-art city destruction game (with automatic 2.5D Canvas fallback when WebGL is unavailable) starring the kid-crafted mossy-olive orb-kaiju (articulated face-culled AO voxel sphere, furrowed V-brows, glowing amber-slit eyes, cavernous fang-lined mouth + hinged lower jaw, splayed 4-fingered upper arms, 4-toed stomp legs, 3-segment sweeping dragon tail, and orbiting ember sparks). Smashable city blocks include diners (`45`), brick apartments (`75`), fuel reactors (`85`), glass skyscrapers (`125`), and props (`10..25`), scaled by a tuned combo multiplier (`1.00x..1.96x`), plus `+12 HP` burgers and `+24 HP` Ace Super Burgers. Hostile police jeeps (`30`), laser-telegraphed tanks (`75`), attack choppers (`110`), and twin-missile **Ace Commander Choppers** (`240`) escalate threat (`1..5`) and drain kaiju HP (`0..100`). Controls: `WASD`/Arrows or bottom-left virtual joystick move; `Space`/Click triggers Smash &amp; Leap-Chomp; `E`/`Shift`/Right-click performs a 360° Tail Whip deflecting projectiles; `Q`/`F` fires the Atomic Ember Roar beam when Rage &ge; 40%; `R` restarts. Win condition: topple all 4 tiers (`125` each) of the purple-and-gold **Bronny Mega Tower** at the active plaza to rescue **Baby Bronny James** (procedural crisp pixel sprite in Lakers gold `#9` jersey), earning `+900` Rescue Bonus + up to `+1,200` Speed Bonus + up to `+900` Health Bonus alongside Destruction and Bounty/Vault totals (`S+`/`S`/`A`/`B`/`C` rank: `S+` &ge; `12,000`, `S` &ge; `9,200`, `A` &ge; `6,500`, `B` &ge; `4,000` on win), capped at `1,000,000` (`GameScoreRules.MaxScore`) and submitting `score` + `maxCombo` to the global leaderboard; Lose condition: HP drops to `0` from enemy fire, still recording earned destruction + bounty/vault score. Deep link: `?game=godzilla-rampage`.

## Endpoints / files
- `GET /api/games` returns the game catalog (`GameScoreRules.Catalog`).
- `GET /api/games/me/bests` returns a dictionary mapping `gameKey` to the signed-in player's personal best score.
- `GET /api/games/{gameKey}/leaderboard` returns `GameLeaderboardView` (top players + signed-in player's record and rank).
- `POST /api/games/{gameKey}/scores` submits `{ score, maxCombo }` and returns `GameScoreSubmissionView`.
- `GET /api/games/{gameKey}/levels`, `GET /api/games/{gameKey}/levels/{id}`, `POST /api/games/{gameKey}/levels`, `PUT /api/games/{gameKey}/levels/{id}`, `DELETE /api/games/{gameKey}/levels/{id}`, and `POST /api/games/{gameKey}/levels/{id}/runs` manage member-created custom levels and course records (`GameLevelRules` and `GameCustomLevelService`).
- Rules live in `GameScoreRules` and `GameLevelRules` (`src/FamilyVault.Files/Security/`); services are `GameScoreService` and `GameCustomLevelService` (`src/FamilyVault.Files/Services/`).
